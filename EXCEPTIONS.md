# A11y Exceptions Log

Registro dos desvios conhecidos em relação à WCAG 2.2 AA que foram aceitos temporariamente (formato do template do [A11Y.md](https://github.com/fecarrico/A11Y.md)). Cada entrada precisa de dono do risco, aprovador, issue de rastreio e data de expiração.

**Situação em 2026-11-19: nenhuma exceção ativa.** Este projeto não aceita desvios de critério WCAG no nível-alvo (AA). Se algum for necessário, registre aqui no mesmo commit que o introduz.

Os itens que parecem exceções, mas são decisões entre alternativas igualmente conformes (por exemplo, `main:focus { outline: none }` no destino do link de salto), estão em [A11Y-DECISIONS.md](A11Y-DECISIONS.md).
